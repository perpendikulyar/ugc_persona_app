# Локальный запуск UGC Persona

Требуется Node.js версии 24.14 или новее. SQLite встроен в Node.js. Зависимости npm нужны для сборки React-интерфейса и Tailwind CSS.

```sh
npm ci
cp .env.example .env
npm start
```

Откройте http://127.0.0.1:3000. Если порт занят, задайте другой `PORT` в `.env`. Для изменения настроек перезапустите приложение. По умолчанию база хранится в `data/persona.sqlite`. Другой путь можно указать в `DATABASE_PATH`.

## Подключения

- **OpenAI.** Заполните `OPENAI_API_KEY` и `OPENAI_MODEL` идентификатором модели с поддержкой Chat Completions. [Справочник OpenAI API](https://developers.openai.com/api/reference/resources/chat)
- **YandexGPT.** Заполните `YANDEX_API_KEY` ключом сервисного аккаунта с доступом к генерации и `YANDEX_MODEL_URI` полным URI вида `gpt://<folder_id>/yandexgpt/latest`. [Справочник API Yandex AI Studio](https://aistudio.yandex.ru/en/docs/ai-studio/text-generation/api-ref/TextGeneration/completion)

- **OpenRouter.** Заполните `OPENROUTER_API_KEY` ключом OpenRouter и укажите `OPENROUTER_MODEL=openrouter/free`, чтобы автоматически выбирать доступную бесплатную модель. Для сравнения с одной и той же моделью укажите её идентификатор с суффиксом `:free`. Бесплатные модели имеют лимиты. [Бесплатные модели OpenRouter](https://openrouter.ai/collections/free-models)
- **Groq.** Заполните `GROQ_API_KEY` ключом GroqCloud и укажите `GROQ_MODEL=openai/gpt-oss-20b` для тестирования на бесплатном тарифе в пределах лимитов аккаунта. [Лимиты GroqCloud](https://console.groq.com/docs/rate-limits)
- **Google AI Studio.** Создайте ключ в [Google AI Studio](https://aistudio.google.com/apikey), укажите его в `GEMINI_API_KEY` и задайте `GEMINI_MODEL=gemini-3.5-flash-lite` или другую доступную проекту текстовую модель. [Тарифы Gemini API](https://ai.google.dev/gemini-api/docs/pricing)
- **GigaChat.** Укажите ключ авторизации из личного кабинета в `GIGACHAT_AUTH_KEY` без префикса `Basic`, модель в `GIGACHAT_MODEL` и scope проекта в `GIGACHAT_SCOPE`. Для физлиц укажите `GIGACHAT_API_PERS`. Сервер сам получает токен доступа. [Авторизация GigaChat](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api)

Приложение запускается с любым числом настроенных подключений. Без них доступны профили и история, в редакторе отображается «Модели не настроены», а генерация недоступна. В разделе «Настройки» доступен тестовый запрос. В разделе «Настройки» можно сохранить модель по умолчанию. Режим «Автоматически» выбирает первое настроенное подключение. Если сохранённая модель недоступна, редактор тоже использует первое доступное подключение. В редакторе можно выбрать другую модель для конкретного черновика. Генерация отправляет профиль, задачу и введённый контекст выбранному провайдеру.

## Сертификат для GigaChat

Корневой сертификат Минцифры находится в `certs/russian-trusted-root-ca.pem`. Приложение добавляет его к стандартному набору доверенных сертификатов Node.js только для OAuth и запросов генерации GigaChat. Достаточно обычного запуска через `npm start`. Проверка TLS остаётся включённой. [Сертификаты GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates)

Сертификат скачан по HTTPS с официального адреса. SHA-256 отпечаток — `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`. [Скачать сертификат Минцифры](https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt)

## Первый черновик

Выберите любого сохранённого персонажа в списке редактора или нажмите «В редактор» рядом с его именем в разделе «Персонажи».

Нажмите «Загрузить пример» в редакторе, выберите модель и создайте ответ Хельги. Отредактируйте текст и сохраните его. Черновик появится в истории с именем персонажа, моделью и исходной генерацией. Чтобы сохранить также вставленную ветку и выбранную реплику, отметьте «Сохранить контекст в истории».

## Отладка запроса

Включите «Режим отладки» в редакторе и нажмите «Показать запрос». В модальном окне появятся системный промпт и пользовательский запрос в Markdown. Их можно скопировать одной кнопкой. Режим работает без настроенной модели и сохраняет текущий черновик в редакторе.

## Разработка интерфейса

React-компоненты находятся в `src/client/`, стили Tailwind — в `src/style.css`. Команда `npm run dev` следит за исходниками и пересобирает интерфейс при изменениях. Чтобы увидеть изменения, обновите страницу. `npm run typecheck` проверяет типы клиента. `npm start` собирает интерфейс перед запуском.
