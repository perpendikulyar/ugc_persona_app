# Инструкции для работы над UGC Persona

- Начинай работу с [согласованного устава](docs/PRODUCT_POSTER.md). В нём описаны объём MVP, критерии приёмки и открытые решения. Согласованные изменения этих решений фиксируй в уставе.
- Храни проектную документацию в `docs/`. Этот файл находится в корне как точка входа для агентов. Исходные примеры персонажей хранятся в `examples/`.
- MVP — локальное веб-приложение на TypeScript и SQLite. Каждый редактор работает со своего компьютера в браузере со своим экземпляром приложения и базой. Общая база для двух редакторов входит в планы после MVP.
- Основной сценарий — сохранить профиль персонажа, выбрать новый топик или ответ, ввести задачу и при необходимости вставить контекст ветки. Редактор проверяет и правит черновик перед ручной публикацией. Первая площадка для пилота — «Женсовет» The Voice.
- В MVP генерация работает через OpenAI API, YandexGPT, OpenRouter, Groq, Google AI Studio и GigaChat. Параметры подключения, идентификаторы моделей и ключи задаются серверными переменными окружения. В браузере редактор выбирает доступное подключение. Локальная модель и память персонажа между обсуждениями входят в планы после MVP.
- Разрабатывай интерфейс на React и TypeScript в `src/client/`. Для оформления используй Tailwind CSS. Общие стили находятся в `src/style.css`, команда `npm run build` собирает клиент и стили.
