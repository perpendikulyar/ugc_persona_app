# UGC Persona

Локальное веб-приложение для подготовки форумных топиков и ответов от лица вымышленных персонажей. Редактор сохраняет биографию, характер и стиль речи персонажа, добавляет задачу и контекст обсуждения, затем правит и копирует черновик для ручной публикации.

Интерфейс написан на React, TypeScript и Tailwind CSS. Сервер работает на Node.js, а персонажи и история черновиков хранятся в локальной SQLite.

## Быстрый запуск

Требуется Node.js 24.14 или новее.

```sh
npm ci
test -f .env || cp .env.example .env
npm start
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Чтобы включить генерацию, укажите ключ и модель хотя бы одного провайдера в `.env`. Поддерживаются OpenAI, YandexGPT, OpenRouter, Groq, Google AI Studio и GigaChat. Без подключения можно редактировать персонажей, открывать историю и просматривать запрос в режиме отладки.
